# AI랭킹닷컴 — Blogger 테마

카테고리별 AI 툴 순위를 보여주는 Blogger(블로거) 테마입니다. damoa.ai처럼 카테고리 안에서 랭킹 리스트를 보여주되, 각 항목을 클릭하면 페이지 이동 없이 같은 화면에서 모달(팝업)로 상세 설명이 열립니다.

**테마 파일(`blogger-theme/theme.xml`) 하나에 8개 카테고리(글쓰기/이미지/영상/코딩/음성/번역/디자인/챗봇), 총 40개의 실제 유명 AI 툴(ChatGPT, Claude, Midjourney, GitHub Copilot, ElevenLabs, DeepL, Canva 등) 정보가 이미 다 채워져 있습니다.** 별도 페이지를 만들거나 위젯에 내용을 입력할 필요 없이, 테마를 붙여넣기만 하면 바로 작동하는 완성형 사이트입니다.

## 설치 순서 (2단계)

1. **테마 업로드**
   Blogger 관리 화면 → 테마(Theme) → 맞춤설정 옆 화살표 → HTML 수정 → `blogger-theme/theme.xml` 내용 전체를 붙여넣고 저장.
   (적용 전에 기존 테마를 "백업/복원"으로 내보내 두면 안전합니다.)

2. **애드센스 ID 교체**
   `theme.xml`에서 `ca-pub-XXXXXXXXXXXXXXXX`로 된 부분(스크립트 태그 포함 총 11곳)을 본인 애드센스 발행자 ID로 모두 교체하세요. 또한 `data-ad-slot` 값(10곳: `0000000000` ~ `0000000009`)도 애드센스에서 발급한 실제 슬롯 번호로 바꿔야 광고가 정상 표시됩니다.

이게 전부입니다. 다른 작업은 필요 없습니다.

## 구조

- 홈 한 화면에 모든 콘텐츠가 들어 있습니다 — 상단 카테고리 카드(`#writing`, `#image` 등 앵커)를 누르면 같은 페이지 안의 해당 섹션으로 스크롤됩니다.
- 각 카테고리 섹션에는 5개 툴의 순위 카드(별점/태그/요약)가 있고, 카드를 클릭하면 모달 팝업으로 더 자세한 설명이 열립니다.
- 모달 안의 설명 텍스트는 페이지에 이미 HTML로 존재합니다(자바스크립트로 나중에 불러오는 방식이 아님) — 구글이 그대로 읽고 색인할 수 있습니다.
- 블로그에 새 글(Post)을 쓰면 홈 하단 "블로그" 섹션에 자동으로 표시됩니다(선택 사항, 안 써도 무방).

## 디자인

- 미니멀 화이트 배경 + 포인트 컬러 1개. `theme.xml` 상단 `:root{--color-point:...}` 값만 바꾸면 전체 톤이 바뀝니다.
- 데스크탑은 사이드바 광고, 모바일은 사이드바를 숨기고 본문 안 광고만 노출(과다 광고 방지).

## SEO(색인)를 위해 적용한 것

- `<title>`, `<meta description>`, canonical, og:image(글 대표 이미지 자동 반영) 태그
- 사이트 전체 `WebSite` 구조화 데이터(검색 기능 포함) + 카테고리별 `ItemList` 구조화 데이터(JSON-LD) — 검색결과에 순위 리스트로 노출될 가능성
- 헤더 검색창(Blogger 기본 검색 위젯)
- 명확한 제목 계층과 내부 링크(홈 → 카테고리 카드 → 랭킹 항목 → 모달)로 크롤링 경로 확보

## 기타 기능

- 별점/평점 표시, "도움이 됐어요" 투표 버튼(브라우저 `localStorage`에 저장 — 방문자 개인 브라우저 기준이며, Blogger에 서버/DB가 없어 전체 방문자 공통 집계는 불가능한 구조적 한계입니다)
- "방문" 링크에는 `rel="nofollow noopener"`가 기본 적용되어 있습니다. 추후 제휴 프로그램(어필리에이트)에 가입해 수익화를 확장하려면, 발급받은 링크로 href를 교체하고 `rel`을 `sponsored`로 바꾸면 됩니다(가입 자체는 본인이 직접 해야 합니다).

## 콘텐츠 갱신

- 각 카테고리 섹션의 툴 정보(이름/설명/별점/링크 등)는 `theme.xml`의 해당 `<section class='cat-section' id='...'>` 블록을 직접 수정하면 됩니다. 순위 변경이나 신규 툴 추가도 같은 방식입니다.

## 주의할 점

- 애드센스 승인 전에는 광고가 보이지 않거나 빈 공간으로 표시될 수 있습니다. 승인 후 정상 노출됩니다.
