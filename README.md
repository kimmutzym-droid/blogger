# AI랭킹닷컴 — Blogger 테마

카테고리별 AI 툴 순위를 보여주는 Blogger(블로거) 테마입니다. damoa.ai처럼 카테고리 안에서 랭킹 리스트를 보여주되, 각 항목을 클릭하면 별도 페이지 이동 없이 같은 화면에서 모달(팝업)로 상세 설명이 열립니다. 애드센스 수익화와 검색 색인을 고려해 설계했습니다.

## 폴더 구성

- `blogger-theme/theme.xml` — Blogger에 업로드할 테마 파일
- `content-templates/01-hero-widget.html` — 홈 상단 소개문구
- `content-templates/02-category-grid-widget.html` — 홈 카테고리 8개 카드
- `content-templates/03-category-page-template.html` — 카테고리 페이지(랭킹 리스트) 템플릿, 8개 카테고리마다 복사해서 사용

## 설치 순서

1. **테마 업로드**
   Blogger 관리 화면 → 테마(Theme) → 맞춤설정 옆 화살표 → HTML 수정 → `theme.xml` 내용 전체를 붙여넣고 저장.
   (적용 전에 기존 테마를 "백업/복원"으로 내보내 두면 안전합니다.)

2. **애드센스 ID 교체**
   `theme.xml`에서 `ca-pub-XXXXXXXXXXXXXXXX`로 된 부분 4곳(스크립트 1곳 + 광고 슬롯 3곳: 사이드바/하단/스크립트 태그)을 본인 애드센스 코드로 교체하세요. `data-ad-slot` 값도 애드센스에서 발급한 실제 슬롯 번호로 바꿔야 광고가 표시됩니다.
   카테고리 페이지 템플릿의 인피드 광고(`03-category-page-template.html` 안의 ins 태그)도 동일하게 교체합니다.

3. **홈 위젯 채우기**
   Blogger 레이아웃(Layout) 화면에서:
   - "소개" 위젯(HTML1) 수정 → `01-hero-widget.html` 내용대로 제목/본문 입력
   - "카테고리 모음" 위젯(HTML2) 수정 → `02-category-grid-widget.html` 내용 붙여넣기 (페이지 만들기 전엔 링크가 404가 나니, 4번 작업 먼저 또는 동시에 진행)

4. **카테고리 페이지 8개 만들기**
   페이지(Pages) → 새 페이지 → `03-category-page-template.html` 내용을 HTML 보기로 붙여넣기.
   8개 카테고리(글쓰기/이미지/영상/코딩/음성/번역/디자인/챗봇) 모두 같은 방식으로 만들고, `[대괄호]`로 표시된 부분을 실제 AI 툴 정보로 교체하세요.
   게시 후 생성된 주소(`/p/xxxx.html`)를 `02-category-grid-widget.html`의 href와 일치시키세요. 메뉴(PageList)는 페이지를 만들면 자동으로 추가/관리할 수 있습니다(레이아웃에서 노출 순서 조정 가능).

5. **페이지 설정 → 검색엔진 환경설정**
   각 페이지 게시 시 "검색 환경설정 설명"에 120자 내 요약을 입력하면 검색결과 노출 문구로 사용됩니다(테마가 자동으로 description 태그에 반영).

## 디자인이 신경 쓴 부분

- 미니멀 화이트 배경 + 포인트 컬러 1개(`--color-point`, `theme.xml` 상단에서 색만 바꾸면 전체 톤 변경 가능)
- 모바일에서 사이드바 광고는 숨기고, 대신 카테고리 페이지 본문 안 인피드 광고로 대체 (광고 과다 노출 방지)
- 랭킹 카드 클릭 시 페이지 이동 없이 모달로 설명 — 사용자 경험은 가볍게 유지하면서, 설명 텍스트 자체는 페이지 HTML에 그대로 존재하므로 구글이 콘텐츠를 그대로 읽고 색인할 수 있습니다(자바스크립트로 나중에 불러오는 방식이 아님)

## SEO(색인)를 위해 적용한 것

- 페이지별 `<title>`, `<meta description>`, canonical 태그 자동 처리
- 카테고리 페이지에 `ItemList` 구조화 데이터(JSON-LD) 템플릿 포함 → 검색결과에 순위 리스트로 노출될 가능성
- 사이트 전체 `WebSite` 구조화 데이터 포함
- 명확한 제목 계층(h1은 홈 1곳, 카테고리 페이지는 h3로 항목 구분 — 필요 시 페이지 제목을 h2로 노출하도록 Blogger 기본 페이지 제목 사용)
- 깨끗한 URL 구조(Blogger 기본 `/p/슬러그.html`)와 내부 링크(홈 → 카테고리 카드 → 랭킹 항목)로 크롤링 경로 확보

## 추천하고 싶은 추가 아이디어 (선택사항, 아직 미구현)

다음은 구현하지 않았지만, 운영하면서 고려해볼 만한 것들입니다. 원하시면 추가로 만들어 드릴 수 있습니다.

1. **"최근 업데이트" 표시** — 각 카테고리 페이지 상단에 "2025.06 업데이트" 같은 날짜를 적어두면 신선도 신호로 SEO에 도움이 되고, 재방문 이유가 됩니다.
2. **검색/필터 기능** — 카테고리가 늘어나면 페이지 상단에 간단한 키워드 검색 박스(Blogger 자체 검색 위젯 활용 가능)
3. **"이번 달 인기" 같은 별도 섹션** — 홈 화면에 전체 카테고리를 아우르는 TOP 5를 따로 노출하면 체류시간이 늘어남
4. **사용자 투표/별점** — Blogger는 서버 코드가 없어 직접 구현이 어렵지만, Google Forms나 외부 위젯 연동으로 "이 순위에 투표하기" 같은 참여 요소를 추가할 수 있음 (선택)
5. **태그별 페이지** — 카테고리 외에 "무료" "한국어 지원" 같은 가로축 필터 페이지를 만들면 롱테일 검색 유입에 유리
6. **수익화 다각화** — 일부 AI 툴은 제휴(Affiliate) 프로그램을 운영하므로, `방문` 버튼 링크에 제휴 링크를 연결하면 애드센스 외 추가 수익 가능 (단, 제휴 링크는 `rel="sponsored"` 표시 권장)
7. **og:image 추가** — 카테고리별 대표 이미지를 만들어 OG 태그에 연결하면 SNS 공유 시 썸네일이 노출되어 클릭률이 올라갑니다.

## 주의할 점

- 애드센스 승인 전에는 광고가 보이지 않거나 빈 공간으로 표시될 수 있습니다. 승인 후 정상 노출됩니다.
- `[대괄호]`를 실제 내용으로 모두 바꾸지 않으면 페이지에 그대로 노출되니, 게시 전 반드시 확인하세요.
- 외부 사이트로 나가는 "방문" 링크에는 `rel="nofollow noopener"`를 이미 넣어두었습니다(제휴 링크가 아니면 유지해도 무방).
